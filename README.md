# Sand_control_sistem-
Веб-инструмент на Python (Streamlit + SQLite) для контроля отгрузки песка. Включает подачу заявок подразделениями с местом выгрузки, учет погрузки экскаваторами, защиту разделов по ролям и паролям, визуализацию объемов через Seaborn и выгрузку отчетов за сутки/месяц в CSV (Excel). Готово к запуску в облаке Streamlit Cloud.
